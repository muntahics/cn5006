My Reflection for week7's learning:

Today's class focused on React Hooks, which are essential for managing state and logic within functional components. Hooks allow specific variables to update immediately when their associated dependencies change. Crucially, these updates do not trigger a full refresh of the application; instead, React efficiently re-renders only the relevant component. This isolation enhances the application's scalability and performance by saving bandwidth and reducing processing time. Ultimately, using State is vital for maintaining dynamic data and handling user interactions seamlessly
