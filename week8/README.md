My Reflection for week8's learning:

Today's class was about Mongoose Librry. Mongoose library is a node package which is written in javascript. 
It is built for easy access to our mongodb database through our codebase. It creates a schema of our documents and uses it as a reference for each operations like save, findAndUpdate, findAndDelete, find and so on. 
It is very helpful to easily manage our no sql mongodb database.
